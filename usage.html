    These are estimates. The app counts its own uploads and address searches and this page adds them up across customers. Counting started with the app update that added this page, so anything used before that, or outside the app, is not included. For the exact figures, use the link on each card.
    Database size Open Firebase usage

    Firebase's free plan allows 50,000 reads and 20,000 writes a day and 1 GiB stored. Reads and writes per day can only be seen in the Firebase console; the counts above show how much is stored.
